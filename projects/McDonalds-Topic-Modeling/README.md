# McDonald's Topic Modeling

## Overview
This project applies Latent Dirichlet Allocation (LDA) to extract business insights from 33k+ McDonald's reviews.

## Contents
- `McDonalds-Topic-Modeling.ipynb`: Full analysis pipeline.
- `McDonald_s_Reviews.csv`: Dataset used.
- `lda_visualization.html`: Interactive pyLDAvis dashboard.
- `requirements.txt`: Python dependencies.
