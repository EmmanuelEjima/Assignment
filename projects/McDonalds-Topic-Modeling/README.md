# McDonald's Store Reviews: Topic Modeling (LDA)

## Project Overview
This project utilizes **Latent Dirichlet Allocation (LDA)** to analyze over 33,000 customer reviews.

## Repository Structure
- `images/`: Visualization plots.
- `dataset/`: Cleaned review data.
- `requirements.txt`: Environment dependencies.
- `McDonalds_LDA.html`: Interactive pyLDAvis visualization.
- `report.pdf`: Comprehensive technical report.
- `McDonalds_Topic_Modelling.ipynb`: Complete analysis workflow.
