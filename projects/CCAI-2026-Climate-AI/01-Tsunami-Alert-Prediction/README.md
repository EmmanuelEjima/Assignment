# Predicting Tsunami Alerts from Earthquake Observations

## CCAI 2026 – Climate AI

This project is part of my participation in the Climate Change AI
Virtual Summer School 2026.

The project applies machine learning to earthquake observations
to predict whether an earthquake is likely to trigger a tsunami alert.
