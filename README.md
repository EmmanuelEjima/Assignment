### 2️⃣ 🍔 McDonald's Customer Reviews Topic Modeling

<div align="center">

![NLP](https://img.shields.io/badge/NLP-Advanced-success?style=flat-square)
![LDA](https://img.shields.io/badge/Topic%20Modeling-LDA-blue?style=flat-square)
![Data](https://img.shields.io/badge/Data-33%2C396%20Reviews-orange?style=flat-square)

</div>

**Advanced NLP project extracting hidden insights from 33,396+ McDonald's customer reviews using LDA**

#### 📊 Project Metrics
- **Reviews Analyzed:** 33,396
- **Topics Discovered:** 6 major themes
- **Text Preprocessing:** Complete cleaning pipeline
- **Visualization:** Interactive pyLDAvis dashboard
- **Business Impact:** Actionable insights for operational improvement

#### 🎯 Key Insights Discovered
- 🍟 **Food Quality** - Most frequently discussed topic
- 🚗 **Drive-Thru & Wait Times** - Service efficiency concerns
- 😊 **Customer Service** - Staff interactions
- 📦 **Order Accuracy** - Fulfillment quality
- 🏪 **Store Operations** - Facility management
- 🪑 **Dining Experience** - Ambiance and comfort

#### 🔗 Quick Links

| 🌐 Interactive LDA | [Open Dashboard](./projects/McDonalds-Topic-Modeling/McDonalds_LDA.html) |
| ☁️ Google Colab | [Run in Colab](https://colab.research.google.com/github/EmmanuelEjima/Data-Science-Machine-Learning-Portfolio/blob/main/projects/McDonalds-Topic-Modeling/McDonalds-Topic-Modeling.ipynb) |

#### 🛠️ Technologies
![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![NLTK](https://img.shields.io/badge/NLTK-Text%20Processing-blue?style=flat-square)

![pyLDAvis](https://img.shields.io/badge/pyLDAvis-Visualization-FF6B6B?style=flat-square)
![Pandas](https://img.shields.io/badge/Pandas-150458?style=flat-square&logo=pandas&logoColor=white)

#### ✨ Key Techniques
- ✅ Text preprocessing with NLTK (tokenization, stemming, lemmatization)
- ✅ Stop word removal and vocabulary building
- ✅ Latent Dirichlet Allocation (LDA) modeling
- ✅ Topic distribution analysis
- ✅ Correlation between topics and customer ratings
- ✅ Interactive visualization with pyLDAvis

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/EmmanuelEjima/Data-Science-Machine-Learning-Portfolio.git
cd Data-Science-Machine-Learning-Portfolio
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Explore a Project

```bash
# Example: Navigate to a project
cd projects/breast-cancer-diagnostic-app

# Open Jupyter Notebook
jupyter notebook Breast_Cancer_Detection.ipynb
```

### Run on Google Colab

Every project has a "Open in Colab" badge - click it to run notebooks directly in your browser without local setup!
